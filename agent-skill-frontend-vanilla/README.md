# agent-skill-frontend-vanilla

> 🎨 HTML5/CSS3/Vanilla JavaScript 现代前端静态页面工程规范 Agent Skill

## 特性

- 🏗️ 语义化 HTML5 结构规范（严禁 div 套娃）
- 🎨 CSS 设计系统（Design Tokens / HSL 调色板 / 微动效）
- ⚡ ES6+ 模块化编程（早返回、handle* 命名、防御性 DOM）
- 🚀 性能优化（WebP/AVIF、IntersectionObserver、CLS 防抖）
- ♿ WCAG AA 无障碍基线
- 🔍 SEO 三件套强制规范

## 安装

### Antigravity / Gemini
\`\`\`bash
cp -r skills/frontend-vanilla ~/.gemini/config/skills/
\`\`\`

### Cursor
\`\`\`bash
cp skills/frontend-vanilla/SKILL.md .cursor/rules/frontend-vanilla.mdc
\`\`\`
