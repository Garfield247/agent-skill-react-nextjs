# agent-skill-react-nextjs

> ⚛️ React 18 + Next.js 15 (App Router) + Vite 现代前端工程规范 Agent Skill

## 特性

- 🖥️ Server Component 优先架构（最小 Client Bundle）
- 🔒 TypeScript 严格类型安全（禁止 any）
- 🪝 React Hooks 最佳实践（handle* 命名、完整依赖声明）
- 📦 状态管理选型矩阵（Zustand/TanStack Query/RHF）
- 🚀 性能优化（Code Splitting / next/image / memo 原则）
- 🔧 排障武器库（Hydration / re-render / CORS 常见问题）

## 安装

### Antigravity / Gemini
\`\`\`bash
cp -r skills/react-nextjs ~/.gemini/config/skills/
\`\`\`

### Cursor
\`\`\`bash
cp skills/react-nextjs/SKILL.md .cursor/rules/react-nextjs.mdc
